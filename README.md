# Gizbit

Installable bank for gizbits (₲).

**Gizbit Network:** https://lukeanthony-del.github.io/gizbit/

Install that page on the main phone. Balances lists each account. New accounts start at 0 gizbits. With+Dep. is where this phone deposits and withdraws.

**Gizbit Terminal:** https://lukeanthony-del.github.io/gizbit/terminal/

Install that page on the other phone. Log in with an account password from Gizbit Network, then deposit or withdraw. The main phone adds or subtracts the gizbits when it is open.
